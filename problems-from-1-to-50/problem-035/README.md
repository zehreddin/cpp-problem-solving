Coin Value Calculator

A C++ program that calculates the total value of different US coins.

The program asks the user to enter the number of:

- Pennies
- Nickels
- Dimes
- Quarters
- Dollars

It then calculates and displays the total amount in both dollars and pennies.

Example:

Enter the number of pennies: 10
Enter the number of nickels: 5
Enter the number of dimes: 3
Enter the number of quarters: 4
Enter the number of dollars: 2

Total in dollars: $3.85
Total in pennies: 385 pennies
